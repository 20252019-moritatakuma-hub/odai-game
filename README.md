# お題当てゲーム(オンライン・複数人)

AIだけが知っているお題を、質問とヒントで当てるブラウザゲームです。
リンクを開くだけで、スマホでもPCでも遊べます。参加する人にアカウントは要りません。

**すべて無料枠で動きます。**

| 役割 | 使うサービス | 料金 |
|---|---|---|
| ページの公開・部屋の管理 | Cloudflare Workers(Durable Objects) | 無料プラン |
| お題・質問への回答・正誤判定 | Google Gemini API | 無料枠 |

クレジットカードの登録は不要です。

---

## 公開の手順(はじめの1回だけ・15分くらい)

### 1. Gemini の APIキーをもらう

1. https://aistudio.google.com/apikey を開き、Googleアカウントでログインします。
2. 「APIキーを作成」(Create API key)を押します。
3. 表示されたキー(`AIza...` で始まる文字列)をコピーして、メモ帳などに控えます。
   **このキーは他人に見せないでください。**

### 2. GitHub にファイルを置く

1. https://github.com/new で新しいリポジトリを作ります(名前は `odai-game` など。Private でも大丈夫です)。
2. 作成後の画面で「uploading an existing file」を押します。
3. zip を展開したフォルダの**中身**(`src`、`public`、`package.json`、`wrangler.jsonc`、`README.md` など)をまとめてドラッグして、「Commit changes」を押します。

### 3. Cloudflare で公開する

1. https://dash.cloudflare.com/sign-up で無料アカウントを作り、ログインします。
2. 左のメニューの「Workers & Pages」→「作成(Create)」を押します。
3. 「リポジトリをインポート(Import a repository)」を選び、GitHub と連携して、手順2のリポジトリを選びます。
4. プロジェクト名は **`odai-game`** にします(設定ファイルの名前と同じにする必要があります)。
   その他の設定は変えずに「デプロイ(Deploy)」を押します。
5. 数分待つと、`https://odai-game.〇〇.workers.dev` のようなURLができます。

### 4. APIキーを登録する

1. Cloudflare で作ったWorker(`odai-game`)を開き、「設定(Settings)」→「変数とシークレット(Variables and Secrets)」へ進みます。
2. 「追加(Add)」を押し、次のように入力して保存します。
   - 種類(Type): **シークレット(Secret)**
   - 名前: `GEMINI_API_KEY`
   - 値: 手順1で控えたキー
3. 保存すると自動で反映されます。

これで完成です。URLを開いて「部屋を作る」から遊べます。

## 遊び方

1. 1人が名前を入れて「部屋を作る」を押します。
2. 「招待リンクをコピー」で出たリンクを友だちに送ります(4文字のコードを伝えても参加できます)。
3. 全員そろったら、ホスト(👑)が「ゲーム開始」を押します。
4. 自分の番に1回質問できます。AIが答えると、次の人の番になります。
5. 回答は**1サイクルに1回**です。自分の番でなくても、いつでも答えられます。
6. 全員の番が一周するとヒントが1つ出ます。
7. 最初に正解した人の勝ちです。8サイクル経っても正解が出なければ、お題を発表して終わります。

困ったとき

- 誰かが抜けて順番が止まったら、ホストが「この番をスキップ」を押します(抜けた人の番は自動でも飛ばされます)。
- ホストが抜けると、残った人がホストの操作をできるようになります。
- ページを再読み込みしても、同じ部屋に戻れます。

## 知っておいてほしいこと

- **無料枠の上限**: Gemini の無料枠には、1分あたり・1日あたりの回数制限があります。友だちと遊ぶ分には十分ですが、上限に達すると「AIが応答できませんでした」と出ます。その場合は少し時間をおいてください(番や回答権は消費されません)。制限の数値は https://ai.google.dev/gemini-api/docs/rate-limits で確認できます。
- **無料枠のデータの扱い**: 無料枠では、送った内容が Google のサービス改善に使われることがあります。ゲームに個人情報は書かないでください。
- **AIの精度**: AIの答えが間違うこともあります。気になったら、みんなで話し合って進めてください。
- 誰もいない部屋は6時間後に自動で消えます。

## 変えたいとき

- 最大サイクル数、最大人数などは `src/index.js` の先頭にある「設定」で変えられます。
- AIのモデルは `wrangler.jsonc` の `GEMINI_MODEL` で変えられます。
- GitHub のファイルを書き換えると、Cloudflare が自動で公開し直します。

## (PCで試したい人向け)テストモード

Node.js が入っていれば、AIなしの決まった返事で動きを確かめられます。

```
npm install
npm run test-mode
```

表示された `http://localhost:8787` を開きます。別のブラウザ(またはシークレットウィンドウ)で開けば、1台で複数人を試せます。
