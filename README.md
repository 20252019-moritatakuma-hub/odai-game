# お題当てゲーム(オンライン・複数人)

AIだけが知っているお題を、質問とヒントで当てるブラウザゲームです。
リンクを開くだけで、スマホでもPCでも遊べます。参加する人にアカウントは要りません。

**すべて無料枠で動きます。**

| 役割 | 使うサービス | 料金 |
|---|---|---|
| ページの公開・部屋の管理 | Cloudflare Workers(Durable Objects) | 無料プラン |
| お題・質問への回答・正誤判定 | Gemini API / Groq / Cloudflare Workers AI | 無料枠 |

クレジットカードの登録は不要です。

## AIの控えリスト

AIは次の順番で試します。上限などで使えないAIは自動で飛ばして、次のAIが答えます。
どのAIが答えたかは、ゲーム画面の返事の上に「AI(〇〇)」と表示されます。

| 順番 | 画面の表示名 | サービス | 必要なキー(Cloudflare の Secret) |
|---|---|---|---|
| 1 | Gemini Flash Lite | Gemini API | `GEMINI_API_KEY` |
| 2 | Gemma 4 | Gemini API | `GEMINI_API_KEY` |
| 3 | Qwen 3.8 | Groq | `GROQ_API_KEY` |
| 4 | gpt-oss-120b | Groq | `GROQ_API_KEY` |
| 5 | Llama 3.3 | Cloudflare Workers AI | 不要 |

順番やモデルは `wrangler.jsonc` の `AI_MODELS` で変えられます。
「サービス:モデル名|表示名」をカンマで区切って並べます(サービスは `gemini` / `groq` / `workers`)。
キーが登録されていないサービスは、自動で飛ばされます。

回答の判定に「完全一致」と出たときは、お題と表記がぴったり同じだったため、AIを使わずに判定しています。

## 公開の手順(はじめの1回だけ・15分くらい)

### 1. Gemini の APIキーをもらう

1. https://aistudio.google.com/apikey を開き、Googleアカウントでログインします。
2. 「APIキーを作成」(Create API key)を押します。
3. 表示されたキー(`AQ.` で始まる文字列)をコピーして、メモ帳などに控えます。
   **このキーは他人に見せないでください。**

### 2. GitHub にファイルを置く

1. https://github.com/new で新しいリポジトリを作ります(名前は `odai-game` など。Private でも大丈夫です)。
2. 作成後の画面で「uploading an existing file」を押します。
3. zip を展開したフォルダの**中身**(`src`、`public`、`package.json`、`wrangler.jsonc`、`README.md` など)をまとめてドラッグして、「Commit changes」を押します。

### 3. Cloudflare で公開する

1. https://dash.cloudflare.com/sign-up で無料アカウントを作り、ログインします。
2. 左のメニューの「Workers & Pages」→「作成(Create)」を押します。
3. 「リポジトリをインポート(Import a repository)」を選び、GitHub と連携して、手順2のリポジトリを選びます。
4. プロジェクト名は **`odai-game`** にします(設定ファイルの名前と同じにする必要があります)。
   その他の設定は変えずに「デプロイ(Deploy)」を押します。
5. 数分待つと、`https://odai-game.〇〇.workers.dev` のようなURLができます。

### 4. APIキーを登録する

1. Cloudflare で作ったWorker(`odai-game`)を開き、「設定(Settings)」→「変数とシークレット(Variables and Secrets)」へ進みます。
2. 「追加(Add)」を押し、次のように入力して保存します。
   - 種類(Type): **シークレット(Secret)**
   - 名前: `GEMINI_API_KEY`
   - 値: 手順1で控えたキー
3. 保存すると自動で反映されます。

これで完成です。URLを開いて「部屋を作る」から遊べます。

## 遊び方

1. 1人が名前を入れて「部屋を作る」を押します。
2. 「招待リンクをコピー」で出たリンクを友だちに送ります(4文字のコードを伝えても参加できます)。
3. 全員そろったら、ホスト(👑)が「ゲーム開始」を押します。開始前に、ホストは「AIの答え方」を選べます。
   - **4択**(最初の設定): 「はい・いいえ・どちらとも言えない・関係ありません」だけで答えます。
   - **自由**: 「いいえ。食べ物ではありません」のように短い補足付きで答え、「何色?」のような質問にも答えます。
   答え方はゲーム中は変えられません(終わったあとに変えられます)。お題は、AIが作る普通のお題と、ネットの闇・自虐・炎上系の「際どいミーム」が混ざって出ます(出題元はゲーム終了時に表示されます)。
4. 自分の番に1回質問できます。AIは「はい」「いいえ」「どちらとも言えない」「関係ありません」のどれかで答え、次の人の番になります。「何色?」のような、はい/いいえで答えられない質問や、「それは〇〇ですか?」と答えを名指しする質問は受け付けず、番も消費しません(答えが分かったら回答欄へ)。
5. 回答は**1サイクルに1回**です。自分の番でなくても、いつでも答えられます。
6. 全員の番が一周したら「回答タイム」です。そのサイクルでまだ回答していない人は、全員回答してください。全員そろうとヒントが1つ出て、次のサイクルに進みます。席を外している人がいるときは、ホストが「回答タイムを終わる」で先に進められます(接続が切れた人は自動で待たなくなります)。
7. 右側(スマホでは下)の「ルームチャット」で、部屋の全員と話せます。観戦中の人も使えます。
8. 誰かの質問をAIが考えている間も、入力欄に書いておけます。回答はそのまま送れます(判定は同時に進みます)。
9. 最初に正解した人の勝ちです。8サイクル経っても正解が出なければ、お題を発表して終わります。

観戦

- ゲーム前・ゲーム後は「👀 観戦する」で観戦に回れます。「🙋 参加する」でいつでも戻れます。ページを開き直しても観戦のままです。
- ゲーム中は「👀 観戦に切り替える」で途中から観戦に回れます(そのゲームには戻れず、次のゲームから参加できます)。自分の番だった場合は次の人に回ります。
- ゲームの途中に来た人は自動で観戦になり、次のゲームから自動で参加します。
- ホストが観戦に回ると、ほかの参加者にホストが移ります。

困ったとき

- 誰かが抜けて順番が止まったら、ホストが「この番をスキップ」を押します(抜けた人の番は自動でも飛ばされます)。
- ホストが抜けると、残った人がホストの操作をできるようになります。
- ページを再読み込みしても、同じ部屋に戻れます。

## 改善メモ

トップ画面の「📝 改善メモを見る・書く」、またはゲーム画面上部の「📝 改善メモ」から開けます。
遊んだ人が「不具合」「改善案」「その他」を書き込めて、全員が見られる掲示板です(部屋に関係なく全体で1つ)。

- 同じ意見には「👍 わかる」を押せます(もう一度押すと取り消し)。
- 連投防止のため、同じ回線からは10秒に1回まで書き込めます。最大500件まで残ります。

### 管理者(対応済み・削除)の設定

1. Cloudflare の Worker の「Runtime variables and secrets」に、Secret を1つ追加します。
   - Name: `ADMIN_KEY`
   - Value: 自分で決めた合言葉(他人に推測されにくいもの)
2. ゲームのURLの最後に `?admin=合言葉` を付けて一度開きます(例: `https://odai-game.〇〇.workers.dev/?admin=合言葉`)。
   そのブラウザが覚えるので、次からは普通に開くだけで、メモに「対応済みにする」「削除」ボタンが出ます。

## 知っておいてほしいこと

- **無料枠の上限**: どのAIにも、1分あたり・1日あたりの回数制限があります。1つが上限に達しても次のAIに切り替わりますが、すべて上限に達すると「すべてのAIが無料枠の上限に達しています」と出ます。その場合は少し時間をおいてください(番や回答権は消費されません)。Gemini の使用量は Google AI Studio、Groq は https://console.groq.com/settings/limits で確認できます。
- **無料枠のデータの扱い**: 無料枠では、送った内容が Google のサービス改善に使われることがあります。ゲームに個人情報は書かないでください。
- **AIの精度**: AIの答えが間違うこともあります。気になったら、みんなで話し合って進めてください。
- 誰もいない部屋は6時間後に自動で消えます。

## 変えたいとき

- 最大サイクル数、最大人数などは `src/index.js` の先頭にある「設定」で変えられます。
- AIの順番やモデルは `wrangler.jsonc` の `AI_MODELS` で変えられます。
- 際どいミームは、ほかのジャンルと同じく「ジャンルの1つ」として出ます(今は23ジャンル中の1つなので約4%)。割合を変えたいときは、`src/index.js` の先頭の `MEME_RATE` に数字を入れます(0.1 = 10回に1回、0 = 出さない、1 = ミームだけ)。
- 「際どいミーム」のお題は `src/memes.js` に入っています。お題・読み・別名・説明メモ・ヒント7つの形で、自由に足したり消したりできます。説明メモはAIが質問に答えるときの参考になるので、具体的に書くほど答えが正確になります。
- GitHub のファイルを書き換えると、Cloudflare が自動で公開し直します。

## (PCで試したい人向け)テストモード

Node.js が入っていれば、AIなしの決まった返事で動きを確かめられます。

```
npm install
npm run test-mode
```

表示された `http://localhost:8787` を開きます。別のブラウザ(またはシークレットウィンドウ)で開けば、1台で複数人を試せます。
